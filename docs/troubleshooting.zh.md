# 常见坑（脱敏）

不点名具体目录站。下列为模式级问题与处理。

| 现象 | 可能原因 | 建议 |
|------|----------|------|
| 提交后无邮件 | 进垃圾箱；或站方只做人工无回执 | 查垃圾箱；库中记 `email_behavior`；到期再探活 |
| 验证链接失效 | 短时效 | 立即处理；过期则重发或重交（问人） |
| 拒信：邮箱类型 | 拒绝 agent / 临时邮箱 | 换域名邮箱（人）或换站 |
| 拒信：地点不一致 | 表单地点与条款 / 隐私不符 | 改产品卡与法律页一致后人确认重交 |
| 报「已存在」 | 早先交过或同 URL 占用 | 库中标 live/pending；勿重复刷 |
| 只要付费才出现在列表 | featured-only | 标准档 skip |
| 要求先互链 | required-backlink | 标准档 skip；升档才写 `/links` |
| 卡在所有权 | 未加 meta/DNS | 人加完 → Agent verify |
| fit 拒信（如只要 AI 工具） | 产品类型不符 | `skip_reason=fit-mismatch` |
| 拒图 / 上传失败 | 比例错、过小、超体积、水印 | 按 [assets.zh.md](assets.zh.md) 重导；或 `missing-media` 跳过 |
| 浏览器卡验证码 | 自动化受限 | 停下来找人；或换无验证码渠道 |

仍遵守日限额与 [免责声明](disclaimer.zh.md)。
