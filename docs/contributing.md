# Contributing / 贡献

**EN:** Issues and PRs that improve **method docs**, empty templates, or translations are welcome. Do **not** open PRs that add filled directory lists, live submission URLs, passwords, cookies, or “how to evade search spam actions.” Keep the default advice paced (about 2–4 real submits/day). CLI/automation fixes belong on branch `old` unless we explicitly invite them onto `main`.

**中文：** 欢迎改进**方法文档**、空模板与翻译的 Issue / PR。请**不要**提交填好的目录名单、实交 live URL、密码、cookie，或「如何规避搜索引擎垃圾链接处理」类内容。默认建议保持控速（每天约 2–4 次真正提交）。CLI / 自动化修复请针对分支 `old`，除非维护者明确邀请合入 `main`。
