# Contributing / 贡献

**EN:** Issues and PRs are welcome for:

1. **Agent compatibility / verification reports** — e.g. “I tried X Agent with this playbook; here’s what worked or broke” (open an [Issue](https://github.com/s87343472/backlink-pilot/issues) even if you are not ready to send a PR).
2. **PRs that mark an Agent verified** — after a recorded pass under [verified-agents.md](verified-agents.md) (follow that page’s checklist; keep ZH/EN twins in sync).
3. **Method docs, empty templates, and translations** — clearer wording, schema fixes, bilingual parity.

Do **not** open PRs that add filled directory lists, live submission URLs, passwords, cookies, or “how to evade search spam actions.” Keep the default advice paced (about 2–4 real submits/day). CLI/automation fixes belong on branch `old` unless we explicitly invite them onto `main`.

**中文：** 欢迎以下 Issue / PR：

1. **Agent 兼容与验证反馈** — 例如「我用某 Agent 按本仓库手册测过，卡在哪 / 哪里能跑」（即使还不准备开 PR，也可先开 [Issue](https://github.com/s87343472/backlink-pilot/issues)）。
2. **把某 Agent 标成已验证的 PR** — 按 [verified-agents.zh.md](verified-agents.zh.md) 文末清单写清证据规则，并同步中英双子页。
3. **方法文档、空模板与翻译** — 表述更清楚、字段/模板修正、中英对照。

请**不要**提交填好的目录名单、实交 live URL、密码、cookie，或「如何规避搜索引擎垃圾链接处理」类内容。默认建议保持控速（每天约 2–4 次真正提交）。CLI / 自动化修复请针对分支 `old`，除非维护者明确邀请合入 `main`。
