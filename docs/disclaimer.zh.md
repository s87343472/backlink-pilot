# 风险免责与建议（必读）

本页说明搜索与外链相关的风险取向，以及本 playbook 的默认建议。**不是法律意见，也不是排名承诺。**

## 必须说清楚的事

- 搜索引擎（含 Google）长期反对**用于操纵排名的链接方案**。短时间、大规模、低相关、模式化的外链，有被视为垃圾链接或触发人工 / 算法处理的风险。
- 外链有来源与质量评价；「目录站链接」价值参差不齐。**数量 ≠ 排名。**
- 本项目是**作业方法说明**，帮助你用 Agent 控速、记账、处理邮件；**不是**黑帽教程，也不保证任何流量或排名结果。

官方文档请自行查阅 Google 搜索中心等公开材料，例如：[Google Search documentation](https://developers.google.com/search/docs)。政策会更新；以官方原文为准，本文不做逐句引用或「规避处罚」指导。

## 默认建议

1. **控速：** 真正提交保持日个位数量级（如每天约 2–4 个）。不要把「一天注册 / 提交几十上百」写成推荐玩法。
2. **相关与诚实：** 产品描述真实；分类匹配；主体地点、联系邮箱与站点条款 / 隐私政策一致。
3. **多样且自然：** 目录只是渠道之一。更应重视产品本身、内容与优质自然提及；向资源列表贡献时遵守目标仓库规范。
4. **可撤销：** 交换链、徽章集中放在 `/links`（或约定页），便于日后下线单条。
5. **付费与强制交换：** 默认跳过付费插队与强制互链。若你自行升档，风险自担。
6. **监测：** 若 Search Console 等出现异常，**暂停**批量动作并自查；本文不展开任何规避手法。
7. **责任：** 使用本 playbook 产生的站点行为与后果由**使用者自负**；作者与维护者不承担损失。
