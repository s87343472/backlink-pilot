# 策略档、节奏与跳过规则

公开文档用「档位」讲方法，不记录你或他人实际交过哪些站。

## 三档对照

| 档位 | 允许 | 禁止 / 默认跳过 |
|------|------|-----------------|
| **保守** | 免费、免费排队 | 付费、强制徽章、互链、点赞换积分 |
| **标准（推荐默认）** | 上栏 + **自愿**挂徽章换 dofollow、域名 meta / DNS 所有权验证 | 付费；**强制**互链 / 交换才收录；点赞换积分（除非单独授权例外） |
| **进取** | 标准 + 小额付费插队（你自设金额上限） | 仍建议谨慎对待强制互链；若放开，只用 `/links` 承载（见 [reciprocity.zh.md](reciprocity.zh.md)） |

## 节奏

- **真正提交：** 每天约 **2–4** 个站。筛站、去重、探活可以批量；提交要控速。
- 同产品、同站不重复交（除非拒信后你确认改字段重交）。
- 多产品时 **轮换**，避免同一邮箱 / 指纹一天打爆。

## 通用跳过标签（示例）

给候选站打标签，入队前过滤：

- `paid` / `featured-only` — 默认跳过  
- `required-backlink` — 标准档跳过  
- `required-badge-to-submit` — 保守档跳过；标准档可评估「自愿徽章换 dofollow」是否不同  
- `upvote-for-credits` — 默认跳过  
- `dead` / `captcha-wall` / `agent-email-rejected` — 跳过或改邮箱后人确认  
- `fit-mismatch`（例如纯 AI 目录 vs 非 AI 产品）— 跳过  

## 人必须拍板的例外

付费、点赞换积分、改条款地点、挂强制徽章、加 DNS / meta 验证码 —— Agent 应停下来问人，不要自行「升档」。
