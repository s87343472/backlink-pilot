# GitHub resource lists (awesome, etc.)

- Read the target repo’s `CONTRIBUTING` / existing entry format before opening a PR  
- Issue vs PR: follow that repo’s norms  
- **Batch PR permission is a human policy:** get explicit OK from the maintainer or account owner; this playbook does not encourage unauthorized bulk PRs  
- Honest descriptions and correct categories; do not spam unrelated entries for links  
- Log progress in your library (e.g. tag `type=github-list`)  

Still bound by the [disclaimer](disclaimer.md): list contributions are normal participation, not an excuse for burst link volume.
