# 交换链、徽章与所有权验证

目录站常见「非现金成本」。先识别类型，再决定是否值得；落地时用独立页，而不是把交换链塞进首页主内容。

## 类型对照

| 类型 | 典型要求 | 常见落地 | 标准档建议 |
|------|----------|----------|------------|
| 交换链 / 互链 | 在你站放对方链接才给 dofollow 或才收录 | 独立页 **`/links`**（或 `/LINKS`）集中存放；页脚 / 关于页链过去 | **默认不接强制互链**；升档后只用 `/links` 承载，并写入外链库「需反链」 |
| 徽章（badge） | 挂「Listed on …」图 / 代码换 dofollow 或曝光 | 可与交换链同页，或页脚徽章区 | **允许自愿**挂徽章换 dofollow；「不挂就不能提交」→ 保守档跳过 |
| 域名所有权 | meta 或 DNS TXT | 人在站点 / DNS 加好 → Agent 点 verify | **允许**；token 记入该次提交，过期前提醒 |
| 点赞 / 评论换积分 | 先互动才能免费发 | — | 默认跳过 |
| 付费插队 / Featured | 花钱加快队列 | — | 默认跳过 |

## `/links` 页规范

业界通用做法：新建链接页存放交换伙伴与徽章，便于管理与下线。

- **路径：** 建议 `https://yoursite.example/links`（大小写随站点习惯）
- **内容：** 伙伴名称 + URL + 一句说明；可选徽章图。模板见 [templates/links-page.example.md](../templates/links-page.example.md)
- **首页：** 不要把一长串交换链接塞进首屏主文；最多放「友情链接」入口指向 `/links`
- **robots / 索引：** 可索引便于对方核查；若 SEO 策略要求 noindex，需在对方要求与自身策略间权衡（利弊自担）
- **Agent 检查：** 若该站 `requires` 含反链 / 徽章，提交前确认约定位置已有对应条目

公开文档用 `Partner Name` / `https://example.com` 占位，**不写真实交换域名**。

## 所有权验证流程

1. 邮件或后台给出 meta content 或 TXT 值  
2. **人**加到站点或 DNS  
3. 人告知 Agent → Agent 打开 verify 链接或点按钮  
4. 账本标记 `ownership_verified` 与截止日  

验证未完成前，排期 / 上线状态通常不可靠。
